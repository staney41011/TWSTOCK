# TWSTOCK 台股策略雷達

本專案保留動能爆發、十字星、隔日沖、MACD 翻紅、可轉債 CBAS、主動 ETF 共振、Druckenmiller、台股聖杯、關鍵分點等策略，並新增 **產業輪動雷達**。

## 產業輪動雷達

- **入口**：首頁「📈 產業輪動雷達」連結，或者直接開啟 sector-rotation.html。
- **四象限**：領先（相對強度高、相對動能加速）、減弱中（高、減速）、改善中（低、加速）、落後（低、減速）。
- **多週期**：1 / 5 / 10 / 20 / 60 個交易日的相對報酬。
- **歷史回放**：最近 24 個可用交易日，播放／暫停／滑桿回放；選中產業顯示近 5 / 10 / 20 日輪動軌跡。
- **排名與穿透**：綜合評分、相對強弱、上漲廣度排序；搜尋、成分股鑽取（顯示近 5 日表現前 30 檔）、CSV 下載。
- **規則式解讀**：根據算得的指標生成簡短觀察敘述，並不冒稱 AI 或實際資金流入。
- **缺數防護**：數據不足時保留最後一次成功資料，前端呈現更新日期與基準來源。

### 指標口徑

使用 main.py 既有 yfinance 股票價量歷史；產業分類使用 twstock.codes；樣本為交易所產業類別下具備足夠歷史行情的股票（排除 ETF 和其他非股票）。產業報酬採**有效成分股等權平均**，非市值加權交易所官方指數。

| 指標 | 計算 |
| --- | --- |
| X（相對強度） | 指定期間產業平均報酬 − 基準報酬（百分點） |
| Y（動能） | 最近 5 日相對報酬 − 前 5 日相對報酬（百分點） |
| 上漲廣度 | 近 5 日報酬正值的有效成分股比例 |
| 量能比 | 近 5 日平均估算成交值 / 近 20 日平均估算成交值 |
| 泡泡大小 | 產業近 20 日平均估算成交值的平方根比例 |
| 估算成交值 | 收盤價 × 成交股數，**不代表法人買賣超或資金淨流入** |
| 綜合評分 | 相對報酬、動能、量能比與上漲廣度的界限加權，供排序研究 |

比較基準優先為 ^TWII（台灣加權指數）；若指數資料不足會明確改用「有效樣本股票等權比較」，不冒稱加權指數。回放各日只使用對應日期及之前的行情，但仍可能存在當前股票池造成的倖存者偏差，不應將輪動歷史視為策略回測績效。

### 首次啟用與自動更新

1. GitHub Actions → Daily Stock Scan → Run workflow。
2. 保持 run_backfill、run_holy_grail_only 都是 false，運行完整掃描。
3. 確認根目錄生成 sector_rotation.json 且有 days 資料，開啟 sector-rotation.html。
4. 之後標準掃描會同步更新 sector_rotation.json；其他只重新跑特定策略的模式不更新產業快照。

Daily Stock Scan 原定每週一至週五整點 UTC 執行；使用原本 workflow 自動 commit / push 的方式更新。若來源斷線或可用樣本不足，保留先前成功快照並在 log 註明原因。

### 本機測試

~~~
